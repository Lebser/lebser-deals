📥 Guide d'Installation

Installez Lebser Deals en quelques minutes et commencez à optimiser vos prix fournisseurs

1

Accédez à Chrome Web Store

Rendez-vous sur le Chrome Web Store pour installer l'extension Lebser Deals.

🔗 Ouvrir Chrome Web Store
ℹ️ Vous devez utiliser Google Chrome ou un navigateur basé sur Chromium (Edge, Brave, etc.)
2

Cherchez "Lebser Deals"

Dans la barre de recherche du Web Store, tapez "Lebser Deals" et appuyez sur Entrée.

Recherchez notre extension dans la barre de recherche en haut à gauche
3

Cliquez sur "Ajouter à Chrome"

Une fois que vous trouvez l'extension Lebser Deals, cliquez sur le bouton "Ajouter à Chrome" sur la droite.

Le bouton bleu "Ajouter à Chrome" se trouve en haut à droite de la fiche produit
4

Confirmez l'installation

Une fenêtre de confirmation s'affichera listant les permissions dont l'extension a besoin. Cliquez sur "Ajouter l'extension" pour confirmer.

⚠️ À propos des permissions :

L'extension demande accès à Google Sheets pour pouvoir importer et exporter vos données. Aucune autre donnée n'est collectée ou utilisée.

5

Vérifiez l'installation

Une fois l'extension installée, vous devriez voir l'icône Lebser Deals dans votre barre d'outils Chrome (en haut à droite).

✓ Installation réussie !

Vous pouvez maintenant cliquer sur l'icône pour ouvrir le tableau de bord de l'extension.

⚙️ Configuration Initiale

Connectez votre Google Sheet

Pour commencer à utiliser Lebser Deals :

  1. Ouvrez l'extension en cliquant sur son icône
  2. Cliquez sur le bouton "Connecter Google Sheets"
  3. Sélectionnez votre compte Google
  4. Acceptez les permissions (l'extension accède uniquement aux sheets que vous autorisez)
  5. Choisissez la feuille de calcul contenant vos données fournisseurs
La connexion utilise le standard OAuth 2.0 de Google - vos identifiants ne sont jamais stockés

Importez vos données

Préparez votre feuille Google Sheets avec vos données fournisseurs :

  • Colonne 1 : Code EAN (ou identifiant produit)
  • Colonne 2 : Nom du produit
  • Colonne 3 : Prix du fournisseur
  • Colonne 4 : Quantité disponible
  • Colonnes suivantes : Tout autre détail utile
💡 Conseil : Plus vos données sont structurées et les codes EAN précis, meilleur sera le matching produit !

Lancez l'analyse

Une fois vos données importées :

  1. Cliquez sur "Analyser les prix"
  2. L'extension compare vos produits avec la base de données globale
  3. Consultez les recommandations et appariements suggérés
  4. Validez ou corrigez les appariements (contribuez au moteur apprenant !)

🔧 Dépannage

❌ L'extension ne s'affiche pas dans la barre d'outils

Cliquez sur l'icône des extensions dans Chrome (en haut à droite, puzzle), puis cherchez Lebser Deals et cliquez sur le pin pour l'épingler dans la barre d'outils.

❌ Erreur de connexion Google Sheets

Assurez-vous que vous avez autorisé l'extension à accéder à Google Sheets. Allez dans vos permissions Google et vérifiez que Lebser Deals est autorisé.

❌ Pas de résultats d'appariement

Vérifiez que vos codes EAN sont valides et correct. L'extension compare les produits en utilisant les EAN comme identifiant principal. Sans EAN valide, le matching peut être moins performant.

❌ L'extension est lente

Si vous avez un très grand nombre de produits (>10 000), essayez de les diviser en plusieurs feuilles et analysez-les séquentiellement.

❓ Autres questions ?

Contactez-nous à contact@lebser.com avec une description de votre problème et nous vous aiderons au plus vite.

💡 Bonnes Pratiques

  • Vérifiez vos codes EAN : Les codes corrects = meilleur matching
  • Normalisez vos noms : Utilisez les noms officiels des produits quand possible
  • Maintenez vos données : Supprimez les produits obsolètes régulièrement
  • Validez les appariements : Contribuez au moteur apprenant pour améliorer la qualité
  • Sauvegardez régulièrement : Google Sheets garde un historique, mais faites des sauvegardes
