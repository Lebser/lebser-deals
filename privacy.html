1. Introduction

Lebser Deals (l'« Extension ») respecte votre vie privée et s'engage à protéger vos données personnelles. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos informations lorsque vous utilisez notre extension.

L'Extension fonctionne entièrement en local sur votre ordinateur. Aucune donnée sensible n'est envoyée vers nos serveurs.

2. Données Collectées

Données locales (stockées sur votre appareil)

L'Extension stocke localement les données suivantes pour fonctionner :

  • Feuilles Google Sheets connectées : Informations de connexion et références aux feuilles que vous autorisez
  • Paramètres d'utilisation : Vos préférences et configurations de l'Extension
  • Cache local : Données temporaires pour optimiser les performances
  • Codes EAN : Codes-barres produits importés ou créés
  • Appariements produits : Vos validations et corrections d'appariement produit

Données partagées volontairement (moteur apprenant)

Optionnellement, vous pouvez contribuer au moteur apprenant global en partageant les corrections que vous validez. Seules les données suivantes peuvent être partagées :

Donnée Exemple Raison
Codes EAN 3017760050129 Standard public GS1, non propriétaire
Noms normalisés « Coca-Cola 1.5L » Noms publics, sans données commerciales
Validations « Ces produits correspondent » Améliorer le moteur de matching
🔒 Données JAMAIS partagées :
  • Tarifs et prix
  • Codes commerciaux internes
  • Informations d'authentification
  • Données clients ou personnelles
  • Historiques de ventes

3. Utilisation des Données

Usage local

Vos données locales sont utilisées uniquement pour :

  • Analyser et comparer les prix fournisseurs
  • Générer des appariements produit recommandés
  • Créer des rapports d'analyse
  • Améliorer les recommandations personnalisées

Usage du moteur apprenant

Les données que vous choisissez de partager sont utilisées pour :

  • Améliorer la qualité : Affiner les algorithmes de matching
  • Construire un consensus : Combiner les validations de plusieurs contributeurs
  • Distribuer les connaissances : Partager les appariements validés avec d'autres utilisateurs
  • Détecter les anomalies : Identifier les contributions spamées ou incorrectes

4. Partage des Données

Vous contrôlez ce qui est partagé

Vous décidez de :

  • Participer ou non au moteur apprenant
  • Quels appariements valider pour le partage
  • Rétirer vos contributions à tout moment

Quand les données sont partagées

Vos contributions sont partagées uniquement si :

  1. Vous avez explicitement validé l'appariement
  2. La contribution répond à nos critères de qualité
  3. Un consensus est atteint (minimum 5 validations, 80% d'accord)

Avec qui les données sont partagées

Les données validées sont partagées avec :

  • Autres utilisateurs Lebser pour améliorer leurs appariements
  • Le système apprenant centralisé pour le calcul du consensus

5. Moteur Apprenant Global

Architecture de confidentialité

Notre moteur apprenant est conçu avec la confidentialité en priorité :

✓ Architecture décentralisée

Vos données commerciales sensibles restent sur votre ordinateur. Seules vos validations anonymisées contribuent au consensus global.

Protection contre les abus

  • Limite de contributions : Maximum 2 validations par utilisateur par jour
  • Validation d'identité : Historique de contributions vérifié
  • Détection d'anomalies : Patterns suspects sont signalés
  • Révocation possible : Contributions frauduleuses peuvent être annulées

Contrôle administrateur

Les administrateurs peuvent :

  • Vérifier la qualité des contributions
  • Retirer les données frauduleuses
  • Ajuster les seuils de consensus
  • Auditer l'intégrité du système

6. Sécurité

Mesures de sécurité

  • Chiffrement local : Les données en transit utilisent HTTPS
  • Validation côté serveur : Les données entrantes sont validées pour exclure les champs sensibles
  • Isolation : Chaque utilisateur a un accès limité à ses propres données
  • Audit : Les modifications importantes sont enregistrées

Sécurité de Google Sheets

L'Extension se connecte à Google Sheets via OAuth 2.0, le standard de sécurité de Google. Nous :

  • N'avons accès qu'aux feuilles que vous autorisez
  • N'avons pas accès à vos identifiants Google
  • Respectons les permissions feuille par feuille que vous définissez

Conformité

L'Extension respecte :

  • RGPD : Réglementation générale sur la protection des données (UE)
  • CCPA : California Consumer Privacy Act (États-Unis)
  • Lois locales : Législations de confidentialité applicables dans votre région

7. Vos Droits

Droits RGPD

Si vous êtes résidant en UE, vous avez le droit de :

  • Accès : Consulter les données que nous avons à votre sujet
  • Rectification : Corriger les données inexactes
  • Suppression : Demander l'effacement de vos données
  • Portabilité : Recevoir vos données dans un format structuré
  • Opposition : Vous opposer au traitement

Droits généraux

Vous pouvez à tout moment :

  • Cesser d'utiliser l'Extension
  • Supprimer vos données locales
  • Retirer vos contributions au moteur apprenant
  • Révoquer l'accès à Google Sheets
  • Nous contacter pour des questions sur vos données
